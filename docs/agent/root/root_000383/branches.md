- Status: `accepted`
- Source phrase: خلاف الموت (maqayis); الحياة ضد الموت والحي ضد الميت (jamhara;sihah); يقال حيي يحيا فهو حي (ayn;tahdhib); الحياة تستعمل للقوة النامية والحساسة والعاقلة والأخروية والباري حي (mufradat)
- What is: يدخل فيه كون الشيء حيا، والحياة والبقاء، والإحياء بعد موت، والحياة الدنيا والآخرة، ووصف الحي الذي لا يموت.
