## B001 - التَّمر المأكول

- English image: date-fruit as food
- Status: `accepted`
- Source phrase: التمر معروف (jamhara)؛ التمر المأكول (maqayis)؛ التمر اسم جنس والواحدة تمرة وجمعها تمرات وتمور (sihah)؛ التمر حمل النخل وجمع التمر تمور وتمران (tahdhib)؛ تامر ذو تمر أو أطعمهم التمر (maqayis;sihah;tahdhib)؛ التمار الذي يبيع التمر والتمري الذي يحبه (maqayis;sihah)؛ المتمر الكثير التمر والمتمور المزود تمرا (maqayis;sihah)
- What is: يدخل فيه التمر والتمرة وجموعه وحمل النخل ومن عنده تمر أو يطعمه أو يبيعه أو يحبه أو يكثر عنده أو يتزود به
- What is not: لا يدخل فيه تجفيف اللحم ولا ألفاظ التامور
