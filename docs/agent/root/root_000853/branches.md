- Status: `accepted`
- Source phrase: فالصدى الذكر من البوم والجمع أصداء (maqayis); الصدى: ذكر البوم (sihah); الصدى يقال لذكر البوم (mufradat)
- What is: يدخل فيه الصَّدَى بمعنى ذكر البوم والطائر الذي يصر بالليل
