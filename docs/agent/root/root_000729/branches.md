## B001 - نزع الجلد والقشر

- English image: stripping off skin or peel
- Status: `accepted`
- Source phrase: إخراج الشيء عن جلده (maqayis)؛ سلخت جلدة الشاة (maqayis)؛ السلخ كشط الإهاب (ayn;tahdhib)؛ سلخت الشاة إذا كشطت عنها جلدها (jamhara)؛ سلخت جلد الشاة (sihah)؛ السلخ نزع جلد الحيوان (mufradat)؛ مسلاخ الحية قشرها (ayn;sihah;tahdhib)
- What is: سلخ جلد الحيوان؛ كشط الإهاب؛ انقشار جلد الحية أو الإنسان؛ المسلاخ قشر أو إهاب
- What is not: انقضاء الشهر والنهار؛ نزع الثياب؛ سقوط بسر النخلة؛ أسماء النبات والعطر
