- Source phrase: الحرام ضد الحلال (maqayis;sihah); الحرمة ما لا يحل لك انتهاكه (ayn;tahdhib); الحرام الممنوع منه (mufradat); حرام على قرية أهلكناها وقرئت وحرم (maqayis;sihah;tahdhib;mufradat)
