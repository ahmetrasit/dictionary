- English image: affair, state, or matter
- Status: `accepted`
- Source phrase: الشأن الخطب (ayn)؛ الشأن الأمر والحال (sihah)؛ الشأن الحال والأمر الذي يتفق ويصلح ولا يقال إلا فيما يعظم من الأحوال والأمور (mufradat)
