- English image: waking for night prayer
- Status: `accepted`
- Source phrase: وإن صلى ليلا فهو متهجد كأنه بصلاته ترك الهجود عنه (maqayis)؛ تهجدوا أي استيقظوا لصلاة أو لأمر (ayn)؛ التهجد التيقظ من النوم (jamhara)؛ منه قيل لصلاة الليل التهجد (sihah)؛ المتهجد فهو القائم إلى الصلاة من النوم آخر الليل (tahdhib)؛ تيقظ بالقرآن والمتهجد المصلي ليلا (mufradat)
- What is: يدخل فيه التهجد بمعنى التيقظ بعد النوم للصلاة أو القيام بالليل والمتهجد المصلي ليلا
- What is not: ليس مجرد النوم ولا تنويم غيره ولا إلقاء البعير جرانه
