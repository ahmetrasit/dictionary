## B001 - الخروج إلى العدو للغزو

- English image: going out against an enemy for a raid or campaign
- Status: `accepted`
- Source phrase: الغزو: الخروج إلى محاربة العدو (mufradat)؛ غزوت العدو غزوا (sihah)؛ غزوت بني فلان أغزوهم غزوا والواحدة غزوة (tahdhib)؛ المغزاة والمغازي مواضع الغزو وتكون المغازي مناقبهم وغزواتهم (ayn)؛ فالأول الغزو والغازي الطالب لذلك (maqayis)
- What is: غزو العدو وبني فلان؛ الغزوة؛ الغازي؛ جماعة الغزاة؛ موضع الغزو والمغازي والغزوات
- What is not: ليس مجرد مغزى الكلام؛ وليس تعسر اللقاح؛ وليس إمهال الدين
