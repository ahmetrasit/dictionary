## B001 - طريق جار وسيرة متبعة

- English image: a running way and followed practice
- Status: `accepted`
- Source phrase: السنة وهي السيرة (maqayis); المسنن طريق يسلك (ayn); السنن الطريقة (sihah); السنة الطريقة المستقيمة المحمودة (tahdhib); سنة الله حكمه وأمره ونهيه (tahdhib)
- What is: يدخل فيه السنن والطريق والسيرة والسنة المحمودة أو الحكم المتبع
- What is not: لا يدخل مطلق السن ولا التحديد ولا الصب إلا من جهة التشبيه بالطريق الجاري
