- Status: `accepted`
- Source phrase: أصل واحد صحيح يدل على تقدير شيء ونفاذ القضاء به (maqayis)؛ منى له الماني أي قدر المقدر (maqayis;sihah;mufradat)؛ المنى القدر (sihah;tahdhib)؛ قدر الله لك ما يسرك (tahdhib)

- What is not: ليس المني ولا مجرد الأمنية ولا اسم الموضع
