- Status: `accepted`
- Source phrase: أصل يدل على صب وانصباب (maqayis)؛ الهمر صب الدمع والماء والمطر (ayn;tahdhib)؛ همر الماء وانهمر فهو هامر منهمر (ayn;tahdhib)؛ همر الماء والدمع يهمر همرا (sihah)؛ انهمر الماء سال (sihah)؛ همره فانهمر (mufradat)؛ الهمرة الدفعة من المطر (tahdhib)
