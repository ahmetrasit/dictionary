- Status: `accepted`
- Source phrase: الأمل الرجاء (maqayis;sihah;tahdhib)؛ أملته آمله وأمله يأمله أملا وتأميلا (maqayis;sihah;tahdhib)؛ إملة أو إملته أي أمله (maqayis;sihah;tahdhib)
