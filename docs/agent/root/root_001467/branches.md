## B001 - التلقيب والنبز باللقب

- English image: labeling by name or nickname
- Status: `accepted`
- Source phrase: النبز وهو اسم كاللقب والتنبيز التسمية (ayn)؛ نبزت الرجل نبزا إذا لقبته أو عبته وتنابز القوم إذا تعايروا ولقب بعضهم بعضا (jamhara)؛ النبز بالتحريك اللقب والنبز بالتسكين المصدر ونبزه أي لقبه وتنابزوا بالألقاب أي لقب بعضهم بعضا (sihah)؛ النبز والنزب والقزي والنقز اللقب ولا تنابزوا بالالقاب (tahdhib)؛ النبز التلقيب (mufradat)
- What is: التسمية بالاسم أو اللقب، ويشمل اللقب الذي يعيب صاحبه أو يكرهه والتعاير بالألقاب
- What is not: ليس قشور الجدام ولا السعف

## B002 - قشور الجدام والسعف

- What is not: ليس التلقيب ولا التعاير بالألقاب
