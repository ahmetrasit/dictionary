## B001 - وثيقة ممسوكة بحق

- English image: security held for a right
- Status: `accepted`
- Source phrase: الرهن الشيء يرهن (maqayis)؛ الرهن معروف؛ رهنت الشيء فلانا رهنا؛ وارتهنه إذا أخذه رهنا (ayn;tahdhib)؛ رهنت الشئ عند فلان ورهنته الشئ وأرهنته الشئ بمعنى (sihah)؛ الرهن ما يوضع وثيقة للدين (mufradat)
- What is: يدخل فيه الرهن المعروف: الشيء الموضوع وثيقة للدين، وفعل رهن الشيء، وكون الشيء مرهونا أو رهينا، وأخذ المرتهن للرهن.
- What is not: ليس هو مجرد الثبوت والدوام، ولا رهان السباق والخطار، ولا الإسلاف أو الغلاء في السلعة، ولا وصف المهزول.
