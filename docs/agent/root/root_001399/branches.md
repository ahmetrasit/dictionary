## B001 - دين المجوس والانتساب إليه أو الإدخال فيه

- English image: Magian religion, affiliation with it, or causing another to enter it
- Status: `accepted`
- Source phrase: هؤلاء المجوس؛ تمجس الرجل إذا صار منهم (maqayis)؛ المجس يشتق من المجوس ومجسوا أولادهم وتمجس القوم (ayn)؛ المجوسية نحلة والمجوسي منسوب إليها والجمع المجوس؛ تمجس الرجل صار منهم ومجسه غيره (sihah)؛ يمجسانه معناه أنهما يعلمانه دين المجوسية؛ المجوس جمع المجوسي؛ تمجس الرجل ومجس غيره (tahdhib)
- What is: يدخل فيه اسم المجوس والمجوسي والمجوسية، وصيرورة المرء منهم بتمجس، وجعل غيره أو تعليمه دين المجوسية بمجسه أو يمجسانه.
- What is not: لا يخرج إلى أصل قياسي آخر؛ والمصادر تنبه إلى العجمة أو التعريب لا إلى معنى عربي مستقل.
