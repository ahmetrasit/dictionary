- English image: elevated place or path
- Status: `accepted`
- Source phrase: الريع الارتفاع من الأرض (maqayis)؛ الريع الطريق (maqayis;sihah)؛ الريع السبيل سلك أو لم يسلك (ayn)؛ المكان المرتفع الذي يبدو من بعيد (mufradat)؛ ريع البئر الجثوة المرتفعة حواليها (mufradat)؛ الجبل الصغير والواحد ريعة (sihah)

- What is not: ليس النماء والزيادة ولا الرجوع والعود ولا أوائل الشيء
