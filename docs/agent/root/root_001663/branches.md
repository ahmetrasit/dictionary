## B001 - تذكير مخوِّف يرق له القلب

- English image: admonishing reminder that softens the heart through warning
- Status: `accepted`
- Source phrase: الوعظ التخويف والعظة الاسم منه (maqayis)؛ التذكير بالخير وما يرق له قلبه (maqayis;ayn;tahdhib;mufradat)؛ النصح والتذكير بالعواقب (sihah)؛ زجر مقترن بتخويف (mufradat)؛ اتعظ قبل الموعظة (ayn;sihah;tahdhib)
- What is: الوعظ والعظة والموعظة: تخويف أو زجر ونصح وتذكير بالخير والعواقب مما يرق له القلب؛ والاتعاظ قبول الموعظة
- What is not: ليس مجرد ذكر بلا نصح ولا تخويف؛ ولا تكرار تعظعظي فرعا مستقلا
