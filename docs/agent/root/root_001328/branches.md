## B001 - الكوب بلا عروة

- English image: cup without a handle
- Status: `accepted`
- Source phrase: الكوب القدح لا عروة له (maqayis;mufradat)؛ الكوب كوز لا عروة له (ayn;sihah)؛ الكوب الإبريق بلا عروة (jamhara)؛ الكوب الكوز المستدير الرأس الذي لا أذن له (tahdhib)
- What is: الكوب والقدح والكوز والإبريق إذا كان إناء للشرب بلا عروة أو بلا أذن
- What is not: ليس الكوبة الطبل ولا الشطرنجة ولا الشرب بالكوب ولا دقة العنق وعظم الرأس
