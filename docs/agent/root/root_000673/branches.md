## B001 - العدد ستة

- English image: the number six
- Status: `accepted`
- Source phrase: ليس فيه إلا ستة (maqayis)؛ ستة وست في الأصل سدسة وسدس (ayn)؛ ستة رجال وست نسوة وأصله سدس (sihah)؛ الست والستة في الأصل سدس وسدسة (tahdhib)؛ في ستة أيام وستين مسكينا فأصل ذلك سدس (mufradat)
- What is: ست وستة وستون وما يتصل بالعدد كالتصغير والجمع والرتبة والتركيب النحوي
- What is not: السدوس للنيلنج أو الطيلسان أو اسم الرجل؛ السدس سهم أو سن البعير؛ الست الكلام القبيح
