- Status: `accepted`
- Source phrase: اليَد الجارحة (mufradat)؛ اليد أصلها يدي وجمعها أيد ويدي (sihah)؛ يديت الرجل إذا ضربت يده (jamhara;sihah;tahdhib;mufradat)؛ رجل ميدي أي مقطوع اليد واليداء وجع اليد (tahdhib)
- What is: اليَد العضو وما يتصل بإصابته أو قطعه أو وجعه أو وقوعه في حبالة
