## B001 - سبأ الاسم والبلد

- English image: Saba as name and place
- Status: `accepted`
- Source phrase: سبأ اسم رجل يجمع عامة قبائل اليمن وهو اسم بلدة أيضا (ayn)؛ سبأ اسم رجل ولد عامة قبائل اليمن (sihah)؛ سبأ هي مدينة تعرف بمأرب (tahdhib)؛ سبأ اسم بلد تفرق أهله (mufradat)؛ سبأ رجل يجمع عامة قبائل اليمن ويسمى أيضا بلدهم بهذا الاسم (maqayis)؛ السبئية من الغلاة ينسبون إلى عبد الله ابن سبإ (sihah)
- What is: اسم رجل يجمع قبائل اليمن واسم بلد أو مدينة وما ينسب إليه
- What is not: ليس شراء الخمر ولا الإحراق ولا التفرق بصيغة المثل

## B002 - شراء الخمر

- English image: buying wine
- Status: `accepted`
- Source phrase: سبأت الخمر اي اشتريتها واسمها السبيئة ومصدرها السباء (ayn)؛ سبأت الخمر سبأ ومسبأ إذا اشتريتها لتشربها (sihah)؛ سبأت الخمر أسبأها سبأ وسباء إذا اشتريتها واستبأتها (tahdhib)؛ سبأت الخمر اشتريتها (mufradat)؛ سباؤها فاشتراؤها ولا يقال ذلك إلا في الخمر (maqayis)
- What is: شراء الخمر خاصة واستباؤها واسمها السباء أو السبيئة واسم الخمار
- What is not: ليس سبي الخمر بغير همز لحملها إلى بلد آخر

- What is: إحراق الجلد أو الشخص بالنار أو الشمس ولذعه بالسياط
- What is not: ليس تقشر الجلد وانسلاخه ولا الحلف الكاذب
