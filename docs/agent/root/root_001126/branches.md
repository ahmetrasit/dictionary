- Status: `accepted`
- Source phrase: فتقت الشيء فتقا (maqayis)؛ الفتق انفتاق رتق كل شيء متصل (ayn)؛ الفتق ضد الرتق (jamhara)؛ فتقت الشئ فتقا شققته (sihah)؛ فتقت السماء بالقطر والأرض بالنبات (tahdhib)؛ الفتق الفصل بين المتصلين وهو ضد الرتق (mufradat)
