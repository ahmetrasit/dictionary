## B002 - ولد البقرة

- English image: calf
- Status: `accepted`
- Source phrase: العجل ولد البقرة (maqayis;jamhara;sihah;tahdhib;mufradat)؛ العجل عجل الثيران (ayn)؛ الأنثى عجلة والعجول مثله والجمع عجاجيل (maqayis;jamhara;sihah;tahdhib)؛ لا يقال لولد الوحشية عجل (jamhara)
- What is: ولد البقرة الأهلي والأنثى عجلة والعجول مثله والجمع عجاجيل
- What is not: ليس العجلة في الأمر ولا العاجل ضد الآجل ولا آلة السقي؛ ولا يقال لولد الوحشية عجل
