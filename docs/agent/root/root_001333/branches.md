## B001 - الكَيّ بالنار

- English image: cauterizing with fire or hot iron
- Status: `accepted`
- Source phrase: كويت بالنار (maqayis)؛ كويته أكويه كيا أي أحرقت جلده بنار أو بحديدة محماة والمكواة الحديدة التي يكوى بها (ayn)؛ كواه يكويه كيا بالنار والكية الموضع الذي يكوى بالميسم (jamhara)؛ الكي معروف وقد كويته فاكتوى والمكواة الميسم (sihah)؛ كوى البيطار وغيره الدابة وغيرها بالمكواة يكويها كيا وكية والرجل يستكوي إذا طلب أن يكوى (tahdhib)؛ كويت الدابة بالنار كيا (mufradat)
- What is: يدخل فيه كَيّ الجلد أو الدابة بالنار أو الحديدة المحماة والمكواة والكية والاكتواء والاستكواء
- What is not: ليس كوة البيت ولا كي التعليل
