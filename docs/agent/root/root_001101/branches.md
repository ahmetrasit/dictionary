## B001 - الباب المحكم الإغلاق وآلته

- Status: `accepted`
- Source phrase: أغلقت الباب فهو مغلق (maqayis); والمغلاق المرتاج والغلاق والغلق ما يفتح به ويغلق (ayn); أغلقت الباب فهو مغلق والاسم الغلق (sihah); باب غلق أي مغلق (tahdhib); الغلق والمغلاق ما يغلق به وأغلقت الباب (mufradat)
