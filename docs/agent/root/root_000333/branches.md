## B001 - حضور ومشاهدة وقرب

- English image: presence, witnessing, and nearness
- Status: `accepted`
- Source phrase: إيراد الشيء ووروده ومشاهدته (maqayis)؛ الحاضر خلاف الغائب وحضرت القوم إذا شهدتهم (jamhara)؛ الحضرة قرب الشيء وبمحضره (ayn;tahdhib)؛ حضرة الرجل قربه وفناؤه وبمشهد منه (sihah)؛ شهادة مكان أو إنسان ومحضرا مشاهدا معاينا (mufradat)
- What is: حضور الشيء أو الشخص ووروده ومشاهدته وقربه ومحضره وما يكون بحضرته
- What is not: الحضر خلاف البدو؛ عدو الدابة؛ الخصومة؛ الأعلام
