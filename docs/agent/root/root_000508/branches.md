## B001 - شق الحلق للذبح

- English image: slitting the throat for slaughter
- Status: `accepted`
- Source phrase: ذبح الشاة ذبحا (maqayis;sihah)؛ الذبح قطع الحلقوم (ayn;tahdhib)؛ الذبح المذبوح (maqayis;tahdhib;mufradat)؛ الذبح ما أعد للذبح (ayn;tahdhib)؛ الذبيح الذي يصلح أن يذبح للنسك (sihah)؛ تذابح القوم أي ذبح بعضهم بعضا (sihah)؛ يذبح بعضهم إثر بعض (mufradat)
- What is: يدخل فيه ذبح الحيوان والإنسان، والذبيح والمذبوح والذبيحة، وما أعد للنسك أو القربان، وتذابح القوم بعضهم بعضا
- What is not: ليس شق الدن أو فارة المسك، ولا أخاديد السيل، ولا شقوق الأصابع
