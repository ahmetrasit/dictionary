- Status: `accepted`
- Source phrase: كلمة تدل على الغطاء (maqayis)؛ سترت الشيء سترا (maqayis;ayn;jamhara;sihah;tahdhib)؛ إذا غطيته (jamhara;sihah)؛ تغطية الشيء (mufradat)؛ السترة ما استترت به (maqayis;ayn;sihah;tahdhib;mufradat)؛ الستار والستارة (maqayis;ayn;jamhara;sihah;tahdhib)؛ الاستتار الاختفاء (mufradat)

- What is not: التغطية الحسية المحضة والمواضع المسماة الستار والإستار في العدد والوزن والسنور
