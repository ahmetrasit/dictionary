## B002 - غلظ الخلق وخشونة الكلام

- English image: coarse character and rough speech
- Status: `accepted`
- Source phrase: رجل فظ كريه الخلق (maqayis)؛ رجل فظ بين الفظاظة والفظاظ (jamhara)؛ الفظ الرجل الغليظ (sihah;tahdhib)؛ الفظ الخشن الكلام والفظظ خشونة في الكلام (tahdhib)؛ الفظ الكريه الخلق (mufradat)

- What is not: ليس ماء الكرش نفسه إلا أصل التشبيه؛ وليس الفظيظ المختلف فيه.

## B003 - الفظيظ ماء التناسل المختلف فيه

- English image: contested reproductive fluid
- Status: `review`
- Source phrase: الفظيظ ماء الفحل (maqayis)؛ ماء الفحل أو ماء المرأة وليس بثبت (jamhara)؛ الفظيظ ماء الفحل في رحم الناقة (tahdhib)
