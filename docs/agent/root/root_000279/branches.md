## B001 - الجَوْف والداخل

- English image: the hollow inside
- Status: `accepted`
- Source phrase: جوف الشيء (maqayis)؛ جوف الإنسان (maqayis;sihah)؛ الجوف معروف وجمعه أجواف (ayn)؛ جوف كل شيء قعره وداخله (jamhara)؛ استجاف الشيء واستجوف أي اتسع (sihah)؛ الرجل الضخم الجوف (sihah)
- What is: جوف الشيء وداخله وقعره وجوف الإنسان وبطنه والأجوف والجوفاء وما اتسع جوفه وضخم جوفه
- What is not: الطعنة الواصلة إلى الجوف؛ الموضع المسمى بالجوف؛ السمك المسمى بالجواف أو الجوفي
