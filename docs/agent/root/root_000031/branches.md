- Status: `accepted`
- Source phrase: الأس أصل البناء (maqayis;jamhara;sihah;tahdhib); أساس البناء (maqayis;sihah;tahdhib); أسست دارا بنيت حدودها ورفعت من قواعدها (ayn;tahdhib); أسس بنيانه جعل له أسا وهو قاعدته (mufradat)
