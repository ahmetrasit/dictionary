- English image: shelter and dwelling
- Status: `accepted`
- Source phrase: أصل واحد وهو المأوى والمآب ومجمع الشمل (maqayis)؛ البيت معروف (jamhara;sihah)؛ البيت سمي بيتا لأنه يبات فيه (tahdhib)؛ أصل البيت مأوى الإنسان بالليل (mufradat)
- What is: المسكن والمأوى والموضع الذي يبات فيه وما يسمى بيتا لمأواه أو جمعه كبيت الله وبيت العنكبوت والخباء والقصر
- What is not: ليس عيال الرجل ولا بيت الشعر ولا عمل الليل نفسه
