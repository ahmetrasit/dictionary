- English image: affinal bond by marriage
- Status: `accepted`
- Source phrase: الصهر حرمة الختونة (ayn;tahdhib)؛ الأصهار أهل بيت المرأة (sihah;mufradat)؛ المتزوج فيهم أصهار (ayn;tahdhib)؛ الإصهار التحرم بجوار أو نسب أو تزوج (sihah;mufradat;maqayis)؛ أصل يدل على قربى (maqayis)
