- Status: `accepted`
- Source phrase: انكشاف الشيء وبروزه (maqayis)؛ أمر جلي واضح وأجل لنا هذا الأمر أي أوضحه وجلا الله عنك المرض (ayn)؛ الجلي نقيض الخفي وجلا لي الخبر وجلوت أي أوضحت وكشفت وانجلى عنه الهم وتجالينا (sihah)؛ أصل الجلو الكشف الظاهر والتجلي قد يكون بالذات وبالأمر والفعل (mufradat)

- What is not: ليس الجلاء عن الوطن ولا جلوة العروس ولا الصقل ولا انحسار الشعر
