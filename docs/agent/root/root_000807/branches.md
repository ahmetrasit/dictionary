- Status: `accepted`
- Source phrase: شققت الشيء أشقه شقا إذا صدعته (maqayis); الشق مصدر قولك شققت والشقاق تشقق الجلد والصدوع في الجبال والأرضين (tahdhib); الشق الخرم الواقع في الشيء وشققته بنصفين (mufradat); شققت الشيء فانشق وشققت الحطب وغيره فتشقق وشق ناب البعير وشق الفجران (sihah;tahdhib)
