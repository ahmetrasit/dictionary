- Status: `accepted`
- Source phrase: الدم أصله دمو (sihah)؛ الدم معروف والقطعة منها دمة واحدة (tahdhib)؛ الجمع دماء وتثنيته دموان ودميان والنسبة إليه دمي ودموي (sihah;tahdhib)

- What is not: ليس الشجة الدامية ولا الحمرة المشبهة بالدم ولا الدمية
