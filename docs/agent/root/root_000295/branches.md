## B001 - القصد إلى المعظم

- Status: `accepted`
- Source phrase: أصل الحج القصد (maqayis;jamhara)؛ الحج كثرة القصد إلى من يعظم (ayn)؛ حججت البيت أحجه حجا (sihah;tahdhib)؛ أصل الحج القصد للزيارة (mufradat)؛ الحجيج الحاج (maqayis;sihah)؛ الحاج أسمعت (maqayis)
