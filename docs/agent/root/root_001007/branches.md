## B001 - النصر مع التعظيم والتوقير

- English image: support with reverence and honoring
- Status: `accepted`
- Source phrase: النصر والتوقير (maqayis)؛ التعزير التعظيم والتوقير (sihah)؛ العزر النصر بالسيف والتعزير النصر باللسان والسيف (tahdhib)؛ التعزير النصرة مع التعظيم (mufradat)
- What is: تعزير الشخص بمعنى نصره وتعظيمه وتوقيره والدفاع عنه والذب عنه
- What is not: ليس التأديب بضرب دون الحد ولا ثمن الكلأ ولا اسم عُزَيْر
