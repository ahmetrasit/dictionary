- Status: `accepted`
- Source phrase: تأيا يتأيا تأييا أي تمكث؛ تأييت الأمر انتظرت إمكانه؛ ليست هذه بدار تئية أي مقام (maqayis)؛ تأيا أي توقف وتمكث؛ منزل تئية أي منزل تلبث وتحبس (sihah)
- What is: يدخل فيه تأيا بمعنى تمكث وتوقف، وتأيي الأمر بمعنى انتظار إمكانه، والتئية بمعنى مقام أو منزل تلبث.

- Status: `accepted`
