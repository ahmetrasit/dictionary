## B001 - إمالة الشيء وليه حتى يلتوي أو ينحرف

- English image: bending or twisting something so it turns aside
- Status: `accepted`
- Source phrase: أصل صحيح يدل على إمالة للشيء (maqayis_variant;maqayis)؛ لويت الحبل ألويه ليا (ayn;tahdhib;mufradat)؛ لويت الحبل فتلته (sihah)؛ لوى يده ولوى برأسه أماله (maqayis_variant;maqayis;mufradat)؛ لاوت الحية الحية إذا التوت عليها (jamhara)
- What is: يدخل فيه فتل الحبل، ولي اليد أو الرأس، والتواء الشيء أو الذنب أو الحية، وكل إمالة حسية صريحة.
- What is not: ليس مطل الدين، ولا الإشارة بالثوب، ولا الذهاب بالشيء، ولا لواء الراية بوصفه اسما مستقلا.

## B002 - لي الدين بالمطل والتأخير

- English image: bending a debt into delay
- Status: `accepted`

- What is: يدخل فيه لوي الدين والغريم والواجد إذا مطل صاحب الحق أو أخر أداءه.
- What is not: ليس مطلق فتل الحبل، ولا الذهاب بالشيء وأخذه، وإن جاورته عبارة ألوى بحقي في بعض المصادر.
